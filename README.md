Strawberry-Pi is a distributed logistics platform designed to model the end-to-end movement of strawberries across a geographically distributed supply network. The system represents farms, warehouses, distribution centers, transport routes, and delivery regions as interconnected nodes, with a Raspberry Pi acting as a miniature cloud server for coordinating and processing logistics data. The platform tracks shipments across the network and provides a centralized operational view of inventory, routes, delivery states, regional demand, and distribution performance. Rather than treating logistics as a simple CRUD application, Strawberry-Pi explores how distributed infrastructure can be used to coordinate physical supply chains, with the Raspberry Pi providing a constrained environment for experimenting with server deployment, networking, data synchronization, and remote monitoring. The project sits at the intersection of Distributed Systems, Cloud Computing, Edge Computing, Network Architecture, Logistics Optimization, and IoT, using a physical computing node to bridge software infrastructure with a real-world distribution network.
